# Tornado Go BRRR!

Pilot game tornado pixel-art chạy trực tiếp trên trình duyệt.

## Cách chơi

- Nhấn liên tục **GENERATE!** trong 5 giây để nạp năng lượng.
- Dùng **WASD**, phím mũi tên hoặc giữ chuột để điều khiển tornado.
- Hút người, xe và vật thể; hoàn thành ba nhiệm vụ trong mỗi lượt 3 phút.
- Tận dụng mưa giông và các storm cell để hồi thêm năng lượng.
- Checkpoint và điểm cao được lưu ngay trên trình duyệt.

Game có phong cách hài hước, hỗn loạn và không máu me.

## Chạy local

Phục vụ thư mục `dist` bằng một static web server, sau đó mở `index.html`.

## Triển khai

Mỗi lần nhánh `main` được cập nhật, GitHub Actions sẽ tự động đưa nội dung trong `dist` lên GitHub Pages.
